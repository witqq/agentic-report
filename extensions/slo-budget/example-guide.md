# Как выбрать цель доступности для внутреннего API

Цель доступности — это обещание: какая доля минут окна должна пройти без ошибок. Всё, что остаётся,
называется бюджетом ошибок, и его тратят сбои, выкладки и эксперименты.

::::section{title="Сколько разрешает каждая цель" id="targets" nav="Цели"}
Каждая следующая девятка уменьшает бюджет в несколько раз. Для внутреннего API, у которого есть повторные
попытки на стороне клиентов, обычно хватает 99,5 %; 99,99 % оставляет на месяц четыре с небольшим минуты,
а такой бюджет съедает одна неудачная выкладка.

:::island{name="slo-budget" hydrate="idle" title="Калькулятор бюджета ошибок"}

| Цель    | Бюджет на 30 дней | Бюджет на 7 дней |
| ------- | ----------------- | ---------------- |
| 99 %    | 7 ч 12 мин        | 1 ч 41 мин       |
| 99,5 %  | 3 ч 36 мин        | 50,4 мин         |
| 99,9 %  | 43,2 мин          | 10,1 мин         |
| 99,95 % | 21,6 мин          | 5 мин            |
| 99,99 % | 4,3 мин           | 1 мин            |

Бюджет — длина окна в минутах, умноженная на единицу минус цель: 30 × 1 440 × 0,001 = 43,2 минуты
для 99,9 %.
:::
::::

::::section{title="Как проверить свой темп" id="pace" nav="Темп"}
Возьмите число плохих минут за прошедшую часть окна и введите его в калькулятор. Скорость расхода 1
значит, что бюджет закончится ровно к концу окна; выше 1 — раньше. Если при выбранной цели скорость
расхода держится выше 1 три окна подряд, цель выбрана строже, чем сервис может выполнить.
::::
