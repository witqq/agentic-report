# Замер сборки agentic-report

Цифры сняты на одной машине одной командой; у каждой указано, когда и чем она получена, чтобы
читатель мог повторить замер.

:::::section{title="Что показал замер" id="numbers" nav="Цифры"}
::::cards
:::key-figure{label="Сборка документа" value="0,36–0,44 с" date="27 сентября 2026, три прогона" source="time node dist/node/cli.js build examples/document"}
Apple M4 Pro, Node.js 24.20. Первый прогон самый медленный: прогревается кэш модулей.
:::

:::key-figure{label="Один файл HTML" value="800 359 байт" date="27 сентября 2026" source="wc -c по результату сборки"}
Внутри страницы шрифты, схема и рантайм; после gzip — 458 377 байт.
:::

:::key-figure{label="Каталог вместо файла" value="668 КБ" date="27 сентября 2026" source="du -sk по выводу --format directory"}
Шрифты и стили вынесены в `assets/` и кэшируются браузером отдельно.
:::
::::
:::::

:::::section{title="Как повторить" id="repeat" nav="Повтор"}
Соберите пакет командой `pnpm build`, затем трижды выполните сборку под `time` и сравните с цифрами
выше. На другой машине время будет другим, размер файла — тем же, пока не поменялся пример.
:::::
