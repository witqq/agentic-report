# Краткий отчёт для принятия решения

**Вымышленный пример.** Организации, показатели, статусы и решения на этой странице нужны для демонстрации
движка отчётов. Перед использованием замените их проверенными данными своего проекта.

:::::section{title="Сначала ясное решение. Масштаб — потом" id="opening" nav="Решение" recipe="hero"}
:::lead
На одной странице читатель видит выбор, понимает доказательства и находит ответственного. Разбираться в
устройстве самого инструмента ему не придётся.
:::

![Светящиеся архитектурные плоскости сходятся к одному ясному маршруту](assets/field.jpg)

:::decision{title="Выбрать обратимый путь"}
Запуск можно начинать после того, как владельцы доказательств и отката подтвердят один и тот же пакет
релиза.
:::
