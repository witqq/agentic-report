# Какой поиск поставить в справочный центр?

**Вымышленный пример.** Варианты, числа и имена ниже — демонстрационные; перед использованием
замените их настоящим вопросом и его доказательствами.

Руководители поддержки выбирают один подход к поиску до мартовского переезда статей. Прочитайте
три варианта, ответьте в форме в конце страницы и выгрузите ответ для команды платформы.

::::::section{title="Вопрос" id="question" nav="Вопрос" recipe="hero"}
:::lead
С первого поиска читатель находит нужную статью в 58% сессий. Переезд — самый дешёвый момент,
чтобы изменить работу поиска.
:::

Команда платформы успеет выпустить до переезда любой из вариантов ниже. Выбор решает, кто ведёт
синонимы, как быстро новые статьи начинают находиться и сколько стоит месяц работы.
::::::

::::::section{title="Три варианта" id="options" nav="Варианты"}
::::cards
:::card{title="Оставить поиск по словам"}
**Без новых затрат.** Статья находится через минуту после публикации. Синонимы остаются ручным
списком, который правит поддержка.
:::
:::card{title="Облачный смысловой поиск"}
**Лучший результат пилота с первого поиска: 74%.** Новая статья индексируется до часа, а счёт
растёт вместе с трафиком.
:::
:::card{title="Гибридное ранжирование"}
**Сначала поиск по словам, поверх — смысловое переранжирование.** 69% в пилоте и ещё один сервис,
который обслуживает команда платформы.
:::
::::

:::disclosure{title="Как пилот считал успех с первого поиска"}
Две недели обезличенных сессий, 4100 поисков; успехом считалось, когда читатель открыл статью и
не искал снова в течение пяти минут.
:::
