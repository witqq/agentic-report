# Find the real implementation

Paths are relative to the named source repository. The Report excerpts show portions of the named implementation; the Screencast excerpt shows the host binding contract of a compatible bridge. These are excerpts rather than complete functions or a recorded execution. Glow/shadow values and displayed frame states are illustrative authored content. The separate packaged [real-code example](../directed-code-execution/report.md) includes complete Report functions; its [preparation helper](../directed-code-execution/prepare.mjs) refreshes those functions and computes their returned values from the selected local package. This walkthrough has no preparation helper or execution recording.

| Repository / file                                    | Function and responsibility                | Concrete boundary                                                                                                                                 |
| ---------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |

For `copy`, the model's destination `content` refers to the source content descriptor; it is not a deep-cloned business value. The browser separately clones the referenced template into the destination DOM body. After `replace @ 3s`, `compositionFrame(..., 4)` returns `shape.content = {text: "Shadow 12 px"}`. A fresh call at 0 returns `{source: "shape"}`, a different Map and no travel. In a film, beat anchors use measured narration instead of these illustrative numeric times.

The resize listener and the clock both lead to the same browser render. `rect()` reads the current geometry after content/entrance changes; connections are not cached in obsolete screen coordinates. Adding a model action belongs in composition.ts and its source contract; changing its picture belongs in the browser renderer; changing speech binding belongs in Screencast's bridge. Printing and reduced motion render final static state. Complete typed source for the Report implementation ships in its repository; a package installation contains the compiled JavaScript.
