# Синтез исследования

**Вымышленный пример.** Все показатели, статусы, организации и решения на этой странице нужны только для
демонстрации движка отчётов; перед использованием замените их проверенными данными проекта.

Смешанная компоновка сохраняет читаемость основного рассуждения, но позволяет насыщенным доказательствами
разделам использовать доступную ширину.

:::callout{kind="info" title="Вопрос"}
Может ли один декларативный исходник согласованно поддерживать отчёты, операционные сводки и выразительные
лендинги?
:::

## Вывод

Переиспользуемая единица — не генератор шаблонов, а единая проверяемая модель страницы, отрисованная общей
системой токенов и небольшой средой выполнения из пакета.

![Четыре компоновки страниц на одном основании](layout-map.ru.svg)

::::cards
:::card{title="Согласованность"}
Каждый примитив использует общие токены цвета, интервалов, типографики, скругления и фокуса.
:::
:::card{title="Адаптивность"}
Оболочки складываются в одну колонку, а широкое содержимое прокручивается локально.

:::card{title="Расширяемость"}

:::

## Рекомендация

:::decision{title="Сохранять единую систему страниц"}
Добавляйте будущие примитивы взаимодействия и визуализации в это основание, а не создавайте отдельные
рендереры для каждой компоновки.
:::
