## Решение

:::decision{title="Использовать один декларативный путь сборки"}
Сохранить Markdown, метаданные, ограниченные partials и локальные ресурсы как публичный источник. Собирать
их в статический результат с помощью рендереров пакета и ограниченного runtime с делегированием событий.
:::

| Фактор                      | Последствие                                                |
| --------------------------- | ---------------------------------------------------------- |
| Автономная переносимость    | Нет удалённого runtime или сетевой загрузки при подготовке |
| Эргономика агента           | Не требуются JSX, CSS или JavaScript                       |
| Проверка безопасности       | Директивы только с данными и явными ограничениями          |
| Детерминированный результат | Байты определяются версией пакета и локальным источником   |
