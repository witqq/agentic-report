## Embedded fonts

The package embeds Latin and Cyrillic subsets of 23 typefaces in `dist/browser/fonts/`, taken from the [Fontsource](https://fontsource.org) packages of the [Google Fonts](https://github.com/google/fonts) releases: variable fonts as one file per alphabet, Fira Sans and PT Mono as one file per weight. Each typeface is used under the SIL Open Font License, Version 1.1; its full licence text ships next to the font files as `OFL.txt`, and `source.json` records the package and version it came from. The fonts are embedded unmodified; built pages carry only the files their theme uses.
